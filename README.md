# E-Commerce SQL Analytics

This project uses PostgreSQL and SQL to analyze the Brazilian Olist e-commerce
dataset, covering data quality, customer and product behavior, sales, delivery,
and customer satisfaction. It also includes a Streamlit dashboard to explore
the results.

For the project phases and progress, see [ROADMAP.md](ROADMAP.md). For
methodology, schema, analysis findings, and technical details, see the
[docs/](docs/) and [reports/](reports/) directories.
