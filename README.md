## HOW TO START THE PROJECT 
in order to start the project you will need `docker`  and `docker compose` installed on your system, then after that you can run the following which will start docker container and also download the data to ingest to the database, and create schema and add data to the tables `docker compose up -d`, after that you can go inside the  container using `docker compose exec ` or even `docker exec ` for example `docker compose exec postgres /bin/bash` , after that you can connect to the postgres using the command `psql -U olist -d olist_analytics -W` where you will be prompted for the password, if you choose to use your own password set the following enviroment variables :  ` POSTGRES_DB , POSTGRES_USER, POSTGRES_PASSWORD`, or you can use the ones set in the `compose.yml` which are used by default
