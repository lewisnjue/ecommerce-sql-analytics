- \l or \list : list available databases, 

- \c <dbname> or \connect <dbname>Switch/connect to a specific database.

- \dt : list all tables in the current database

- \dt *.* : list all the tables across all schemas 

- \d : List all tables, views, and sequences in the current database

- \d <table_name> : describe a table 

- \du or \dg : List all users/roles and their privileges.

- \df : list fucntions 

- \dv : list views
